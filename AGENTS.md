# AGENTS.md

## Project

Static landing page for **Rincón Verde** — eco-tourism site in Pocora, Guácimo, Limón, Costa Rica. Single `index.html`, no build system, no dependencies.

## Key Files

- `index.html` — the entire site (HTML + inline CSS + minimal JS)
- `vision.md` — objectives, audience, content requirements
- `SKILL.md` — design principles (follow when modifying visuals)

## Conventions

- Edit `index.html` directly. No toolchain.
- CSS is inline in `<style>` — no external files.
- WhatsApp is the primary conversion: `https://wa.me/50600000000?text=...`
- Mobile-first responsive design. Must work on slow connections (rural area).
- Bilingual: Spanish primary, basic English section with toggle.
- Google Fonts: Cormorant Garamond (display) + Inter (body).
- Prefers-reduced-motion is respected.

## Placeholder Content

- Phone number `50600000000` needs replacing with real WhatsApp number.
- Gallery items are placeholders — need real images.
- Visitor photos are placeholders — need real photos.
- Waze embed uses generic query — may need specific coordinates.
